# Zameel v1.3.8 – Graduation Book UI Repair

- Removed the explanatory banner from the top of the book.
- Added clear outer spacing and a constrained book viewport so the spread does not touch the screen edges.
- Moved editing controls out of the pages into a dedicated toolbar below the book.
- Pen mode is now explicit; freehand drawing no longer steals gestures unless the pen is active.
- The toolbar targets the current user's own two pages, so the owner can still browse/manage other participants without accidentally editing their pages.
- Preserved image manipulation, text/sticker manipulation, undo/redo and save.
- Preserved sharing, participant management, hide/show and PDF export.
- Preserved the Zameel turquoise/water identity.
- Build number bumped to 1.3.8+25.
