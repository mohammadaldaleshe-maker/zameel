# Zameel 076 — التسجيل الموثق وراديو Zameel وتحدي أجمل كلية

## التسجيل

- الاسم الأول واسم الأب واسم العائلة إلزامية.
- الطالب يختار ظهور: الاسم مع الأب، أو الاسم مع العائلة، أو الأسماء الثلاثة.
- الهاتف والبريد إلزاميان، والتحقق يتم عبر واحد منهما يختاره الطالب.
- الجامعة والكلية والتخصص تؤخذ من القوائم المترابطة الموجودة في التطبيق.
- السنة والجنس إلزاميان.
- البيانات القانونية ووسائل الاتصال تحفظ في `zameel_registration_profiles` بسياسات مالك الحساب فقط.
- تسجيل الدخول يقبل البريد أو رقم الهاتف.

## راديو Zameel

- شاشة وأيقونة مستقلة.
- تسجيل حتى 120 ثانية، معروف أو مجهول.
- بلاغ واحد لكل مستخدم، ويُخفى المقطع بعد بلاغين مستقلين.
- كتم صاحب المقطع لمدة أسبوع.
- انتهاء دورة المقاطع الساعة 07:00 بتوقيت الأردن.
- الحذف الفعلي من Storage يتم بواسطة `daily-social-maintenance`.

## تحدي أجمل كلية

- شاشة وأيقونة مستقلة عن الراديو.
- صورة واحدة للمستخدم في الدورة اليومية.
- استقبال الصور والتصويت من 07:00 إلى 20:00 بتوقيت الأردن.
- اختيار أعلى صورة في 20:00؛ التعادل يحسم بالأسبق نشرًا.
- الإعجاب، التبليغ، والتنزيل متاحة.
- تُخفى الصورة بعد بلاغين مستقلين.

## خطوات الخادم بعد تطبيق Migration 076

1. انشر الدالة: `npx supabase@latest functions deploy daily-social-maintenance --no-verify-jwt`.
2. أنشئ سرًا قويًا: `npx supabase@latest secrets set ZAMEEL_MAINTENANCE_SECRET=<secret>`.
3. استدعِ الدالة من Supabase Cron عند 04:00 و17:00 UTC يوميًا مع ترويسة `x-zameel-maintenance-secret`.
   هذان الموعدان يساويان 07:00 و20:00 بتوقيت الأردن.

لا تغيّر هذه الإضافة جداول الدردشة أو المكالمات أو القصص أو الكتب أو لَمّة.
