# مراجعة أداء تحديث 136

شملت المراجعة فحص Dart لجميع lib وtest ومسح مسارات التحميل والتوقيت والوسائط عبر ملفات الشاشات والخدمات. هذا فحص مصدر واختبارات منطقية، وليس قياسًا على الهاتف أو وعدًا بزوال أي تأخير محتمل في الشبكة.

| المسار | النتيجة والإجراء |
| --- | --- |
| الملف الشخصي | أزيل انتظار الحضور قبل الاستعلام الأساسي. يظهر الغلاف والاسم فور وصول بيانات المستخدم؛ الإحصاءات في طلبات متزامنة مستقلة. |
| سجل منشورات الملف | 30 منشورًا لكل دفعة وزر عرض المزيد. العدد والإعجابات والتعليقات الإجمالية يحسبها الخادم وفق RLS؛ لا يفقد المستخدم الوصول إلى المنشورات الأقدم. |
| وسائط الملف والبحث | لا تُوقّع كل روابط الوسائط قبل عرض الصفحة أو نتائج البحث. الصور تستخدم التخزين المؤقت وGallery/VideoSource يحلان الرابط عند استخدامه. |
| الدخول | أزيل تنزيل سجل منشورات المستخدم غير المستخدم تلقائيًا من UserProvider. تحميل المنشورات الفعلي بقي في الصفحة المخصصة. |
| الرئيسية | تحميلها كان يفصل النص عن الوسائط ويستخدم لقطة محلية وطلبات مشتركة مسبقًا. أضيف منع تداخل طلبات قائمة الترويج. |
| الدردشة | الحضور وبيانات المجموعة لا يحجزان قائمة الزملاء. فتح شريك محدد لا ينتظر تحميل القائمة. لا يؤخر تسجيل القراءة ظهور الرسائل. احتُفظ بترتيب الإرسال والمصالحة والتكرار. |
| الفيديو | تحديث واجهة شريط التقدم لا يتجاوز 5 مرات في الثانية؛ حساب ثواني المشاهدة يبقى على كل نبضة. لم يتغير التشغيل أو الصوت أو المكالمات. |
| الكتب | منع تداخل تحديث القائمة، مهلة لطلب الشبكة، وعدم مسح البيانات المعروضة عند فشل تحديث لاحق. |
| البحث | رقم جيل للطلب يمنع رجوع نتيجة قديمة عند تغيير النص، حتى عند إعادة نفس عبارة البحث. |
| ميزات الإدارة وحالة الحساب | توقف المؤقتات في خلفية التطبيق. لا يعاد بناء كل الصفحات عندما تصل مفاتيح ببيانات مطابقة. بقيت مراجعة الصلاحيات والتحقق عند الاستئناف. |
| الوسائط المشتركة | عمليات حل الروابط على دفعات محدودة؛ حافظت على ذاكرة الروابط الموقعة المرتبطة بالحساب ومنع تنزيل مقاطع كاملة قبل التشغيل. |
| القصص والكليبسات واللعبة | كانت تستخدم منع تداخل/تحميلًا مؤجلًا/مراقبة دورة التطبيق؛ لم تُبدَّل أنظمة التشغيل أو مواقيت اللعبة. |
| SQL | أعيد استخدام فهارس المنشورات والمتابعة الموجودة. أضيف فهرس محدد لإشعارات الموافقة وتفاعلات الصور. لا حذف بيانات ولا إعادة ضبط للأرصدة والأسئلة. |

التجربة المطلوبة بعد البناء: قياس فتح الملف الشخصي والرئيسية والدردشة والكتب على الشبكة والهاتف نفسيهما، وتجربة أكثر من 30 منشورًا، صور خاصة وحظر، عدة فيديوهات، الانتقال بين التطبيقات، وعرض نتائج الضعف أو الأخطاء إن بقيت. لم تُقَس أزمنة الهاتف بعد.
