# تحديث زميل 137

## التعديلات
- الإعدادات ← مظهر التطبيق: زميل الأصلي، فاتح، داكن، حسب إعدادات الهاتف. يحفظ الاختيار محليًا ويطبق مباشرة دون إعادة إنشاء الصفحات أو فقدان حالتها. تبقى هوية الشعار وألوان العلامة الزرقاء والتنبيهات ثابتة، وتبقى عارضات الوسائط بخلفيتها المناسبة للمشاهدة.
- مساحة صورة أو فيديو المنشور 65% من ارتفاع الشاشة. إزالة قيد 85% على عرض المنشور؛ الحفاظ على تصغير النص السابق وأزرار التفاعل. الصور كاملة دون قص، والفيديو يحتفظ بأبعاده. الصور العمودية الضيقة طبيعيًا قد تبقى لها مساحة جانبية عند الاحتواء دون تشويه.
- علامة التوثيق مرتبطة بمعرّف الحساب، وتظهر بجانب أسماء الأشخاص في التعليقات والدردشة والمجموعات والأصدقاء والبحث والإشعارات والقصص والكليبسات والكتب والاستطلاعات والمكالمات والاجتماعات والكويز وثقة أو غدر والراديو غير المجهول. الهويات المجهولة داخل الألعاب والراديو تبقى مجهولة؛ في ثقة أو غدر يظهر التوثيق عند ظهور اسم الخصم بعد انتهاء المباراة.
- قراءة علامات التوثيق على دفعات بحد 100 حساب؛ احترام صلاحيات قراءة الملفات، إخفاء العلامة عند انتهاء المدة، تحديث دوري أثناء وجود التطبيق في المقدمة.
- لوحة التحكم ← الترويج ← توثيق الحسابات — الطلبات. أزيل الزر من المستخدمين؛ التحقق من صلاحية الشاشة في الخادم وقاعدة البيانات أصبح للترويج كذلك. صلاحيتا verification.read وverification.manage مستقلتان؛ الموظف يحتاج السماح له بشاشة الترويج وصلاحياتها المناسبة.
- سعر التوثيق لم يتغير: دينار واحد لكل شهر تقويمي، والمحفظة والمراجعة اليدوية والكود والتجديد كما في 136.

## التنفيذ خطوة خطوة
نزّل الحزمتين والسكربت إلى Downloads، ثم في PowerShell:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
& "$env:USERPROFILE\Downloads\APPLY_UPDATE_137.ps1" -Stage Prepare
```
بعد نجاح التحضير:

```powershell
$zameelUpdate137 = Get-Content -LiteralPath "$env:USERPROFILE\Downloads\Zameel_Update_137_Path.txt" -Raw
$zameelScript137 = Join-Path $env:USERPROFILE 'Downloads\APPLY_UPDATE_137.ps1'
& $zameelScript137 -Stage Copy -UpdateRoot $zameelUpdate137
if (-not $?) { throw 'Copy failed; stopped' }
& $zameelScript137 -Stage Check -UpdateRoot $zameelUpdate137
if (-not $?) { throw 'Checks failed; stopped' }
```
لا تنفذ SQL أو النشر إذا فشل الفحص. بعد النجاح، انسخ ملف SQL الجديد من PowerShell:

```powershell
$zameelAppRepo = Join-Path $env:USERPROFILE 'Desktop\2027\zameel-feature-control'
Get-Content -LiteralPath "$zameelAppRepo\supabase\migrations\20261004190001_137_appearance_badges_promotions.sql" -Raw -Encoding UTF8 -ErrorAction Stop | Set-Clipboard
```
الصق محتوى الحافظة فقط في Supabase SQL Editor وشغله. يتطلب وجود تحديث 136 المطبق سابقًا، ولا يعيد تشغيل ملفات 133/135/136.
بعد نجاح SQL: DeployFunction، ثم CommitAdmin وCommitApp، بنفس ترتيب المراحل المعتاد. لا يتضمن التحديث حذف بيانات أو تغيير أسئلة الكويز أو أرصدة اللعبة.

## الفحص بعد البناء والتثبيت
- تبديل المظاهر الأربعة؛ إعادة فتح التطبيق؛ الكتابة والحقول والقوائم والبحث والدردشة في الفاتح والداكن، وعدم فقدان الصفحة أو مسودة النص عند التبديل.
- صورة عمودية وأفقية وألبوم مختلط وفيديو: مساحة 65% من ارتفاع الشاشة وأبعاد صحيحة، والسحب والتكبير والتفاعل يعمل.
- التوثيق بجانب الأسماء في المسارات المذكورة، حسابان يحملان الاسم نفسه، وحساب غير موثق. تحقق من الاسم والكود والمبلغ في الطلبات تحت الترويج.
- اختبار الميزات السابقة على الهاتف. اختبارات Flutter الأصلية وبناء Android لم تُشغّل في بيئة تجهيز الحزمة؛ مرحلة Check على Windows مطلوبة.
