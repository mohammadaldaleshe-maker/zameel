# صيانة زميل 143 — الإصدار 2.0.8 والبناء 17

## التعديلات
- السماعة الخارجية: ضبط وضع الاتصال ومسار الصوت الفعلي على Android، وتغيير حالة الزر بعد نجاح الطلب. الإبقاء على مسار iOS.
- مرفقات الدردشة: قائمة صور وفيديو من الاستديو، وخيار ملفات مستقل.
- الرسائل الصوتية: إذن الميكروفون، تسجيل حتى دقيقتين، إيقاف ومعاينة وإلغاء وإرسال وتشغيل، وتنظيف الملف المؤقت.
- عدّاد مدة المكالمة يبدأ عند اتصال WebRTC الفعلي.
- مهلة الرد 45 ثانية في التطبيق وإشعار المكالمة، مع منع قبول مكالمة منتهية على الخادم؛ إظهار «لم يتم الرد» للمتصل عند انتهاء المهلة.
- بطاقات الإشعارات تستخدم خلفيات المظهر، مع الحفاظ على تمييز المقروء وغير المقروء.
- تسجيل الدخول يعرض رسائل عربية مفهومة بدل الاستثناء البرمجي.
- نسيت كلمة المرور: رمز استعادة من البريد، تحقق، كلمة مرور جديدة وتأكيدها، ثم العودة لتسجيل الدخول.
- دعم واتساب: فتح المحادثة مع +962792009821 مباشرة؛ رابط ويب بديل عند عدم توفر التطبيق.
- ملاحظة الحساب المحذوف التي لم تتكرر: إعادة اختبار فقط؛ لم نغيّر المصادقة بناءً على خلل غير مثبت.

## التطبيق خطوة خطوة
جميع الأوامر أدناه في PowerShell، وSQL فقط في محرر Supabase. لا يوجد بناء Android محلي أو تنزيل NDK.

1. ضع ZIP وAPPLY_UPDATE_143.ps1 في Downloads. نفّذ:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
& "$env:USERPROFILE\Downloads\APPLY_UPDATE_143.ps1" -Stage Prepare
if (-not $?) { throw 'Preparation failed; stopped' }
```
2. احتفظ بمسار Update root. ثم:
```powershell
$zameelUpdate143 = [IO.File]::ReadAllText((Join-Path $env:USERPROFILE 'Downloads\Zameel_Update_143_Path.txt')).Trim()
$zameelScript143 = Join-Path $env:USERPROFILE 'Downloads\APPLY_UPDATE_143.ps1'
& $zameelScript143 -Stage Copy -UpdateRoot $zameelUpdate143
if (-not $?) { throw 'Copy failed; stopped' }
& $zameelScript143 -Stage Check -UpdateRoot $zameelUpdate143
if (-not $?) { throw 'Checks failed; stopped' }
```
3. Stage Sql1 ينسخ SQL للصوت ومهلة المكالمة. الصقه في Supabase SQL Editor وشغّله؛ لا تلصق أمر PowerShell في SQL.
4. Stage RecoveryTemplate ينسخ HTML. في Supabase: Authentication > Emails > Templates > Reset password، استبدل جسم قالب استعادة كلمة المرور فقط ثم Save. يجب أن يظهر {{ .Token }} في القالب. قالب Confirm signup وMagic Link يبقيان كما هما. يعتمد التدفق على OTP من 6 أرقام وإعداد SMTP الحالي.
5. Stage Sql2 ينسخ تسجيل 2.0.8+17. شغّله في SQL Editor.
6. Stage DeployFunction ينشر send-push-notifications باستخدام سر webhook الموجود. لا ترسل أي مفاتيح أو كلمات مرور إلى المحادثة.
7. Stage CommitApp يرفع ملفات الحزمة فقط إلى main. شغّل بناء GitHub المعتاد وثبّت النسخة على الهاتفين.

## الاختبار على الهاتفين
- مكالمات صوت وفيديو: السماعة الخارجية تشغيل/إيقاف، عدّاد يبدأ بعد الاتصال، إنهاء/رفض/إلغاء، مكالمة ثانية.
- عدم الرد: مهلة 45 ثانية من إنشاء الدعوة، توقف الرنين وظهور «لم يتم الرد». زمن وصول الإشعار يؤثر في مدة الرنين المتبقية، ولا يمدّد المهلة.
- استديو الصور والفيديو، ومرفق ملف، ورسالة صوتية مع معاينة وإلغاء وتشغيل لدى الطرف الآخر.
- إشعارات مقروءة وغير مقروءة في المظهر الأصلي والفاتح والداكن.
- كلمة مرور خاطئة وحساب محذوف يجب أن يُرفضا برسالة مفهومة.
- الاستعادة: البريد يصل، رمز خاطئ يُرفض، الصحيح يسمح بالحفظ، كلمة المرور القديمة تُرفض والجديدة تعمل. إلغاء الاستعادة لا يترك جلسة استعادة مفتوحة.
- الدعم يفتح محادثة واتساب مباشرة.
- اختبارات الرنين والهاتف مقفل والتطبيق مغلق وتوجيه إشعار التعليق والمحادثة كما نجحت في 142.
