# زميل 134 — التسجيل العام، ثقة أم غدر، وترويج المنشورات

هذه نسخ مصدر كاملة للتطبيق ولوحة الإدارة. لا تحتوي APK أو مثبت Windows. لم ننشر خدمات أو نعدّل قاعدة الإنتاج.

## خطوات قاعدة البيانات

نفّذ الملفات التالية كاملة وبالترتيب في Supabase SQL Editor، من مجلد supabase/migrations في إحدى النسختين فقط:

1. 20261003180001_133_open_registration.sql
2. 20261003180002_133_trust_game.sql
3. 20261003180003_133_trust_administration.sql
4. 20261003180004_133_trust_scheduler.sql
5. 20261003180005_133_post_promotions.sql

إن سبق تنفيذ أحدها بنجاح، لا تحتاج تكراره؛ اختُبرت إعادة تنفيذ الملفات 1 و2 و3 و5 دون فقدان البيانات. الملف الرابع يحتاج pg_cron: فعّله من Database / Extensions إذا لم يكن موجودًا. لا تشغّل migrations القديمة ولا تعِد استيراد بنك الأسئلة.

تحقق بعد التنفيذ:

```sql
select jobname,schedule,active from cron.job where jobname='zameel-trust-sweep';
select status,count(*) as question_count from public.zameel_quiz_questions group by status;
```

يجب بقاء 2000 سؤال منشور بحسب حالتك الحالية. لا تفعّل اللعبة قبل نجاح الجدولة كل دقيقة. اللعبة مخفية افتراضيًا حتى تفعيل trust_game من لوحة التحكم؛ الترويج متاح بعد تنفيذ ملفه ويمكن إيقافه من مفاتيح الميزات.

## لوحة التحكم

من مجلد مصدر الإدارة شغّل:

```powershell
npx supabase functions deploy admin-console
npm ci
node --test test/*.mjs
npm run build:windows
```

البناء على Windows يتطلب متطلبات Tauri وRust، ويمكن استخدام GitHub Actions الموجود. الصلاحيات الجديدة: trust.read وtrust.manage وtrust.coins وtrust.reports، وكذلك promotions.read وpromotions.manage. العمليات الجديدة تتطلب نطاقًا إداريًا عامًا. السوبر أدمن يحصل على الصلاحيات الجديدة، ويمكنه تخصيصها للموظفين.

## تطبيق Flutter

استخرج النسخة إلى مجلد جديد، واحتفظ بإعدادات مشروعك الحالية ومفاتيح توقيع Android. شغّل:

```powershell
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

يمكن استخدام مسار بناء Android الموجود في GitHub. رقم التطبيق بقي 2.0.0+9؛ ارفع رقم البناء قبل إصدار تحديث للمتجر حسب آخر رقم استخدمته.

## الميزات

- التسجيل: «عضو مجتمع» متاح للجميع دون جامعة، أو «طالب» مع الجامعة والكلية والتخصص والدرجة (بكالوريوس/ماجستير/دكتوراه) والرقم الجامعي. يبقى تحقق البريد أو الهاتف مطلوبًا، والحسابات السابقة محفوظة. SMS يتطلب مزود الرسائل المهيأ في Supabase.
- ثقة أم غدر: لاعبان عشوائيان، 10 أسئلة منشورة من الكويز، 90 ثانية لكل سؤال، ودردشة خاصة بالمباراة. يبدأ الحساب بمحفظة افتراضية مقدارها 1000 عملة مرة واحدة، ويمكن تعديل الإعداد إداريًا. حجز 50 لكل لاعب عند بدء المباراة فقط. المكافآت 10 إلى 100، بإجمالي أقصى 550.
- ثقة/ثقة: إعادة الحجز وتقسيم المكافأة. غدر/ثقة: الغادر يسترد حجزه ويأخذ المكافأة وحجز الخصم. غدر/غدر: خسارة الحجزين وإلغاء المكافأة. خطأ أو انتهاء وقت السؤال يلغي مكافأته فقط.
- الانسحاب المتعمد أو عدم العودة خلال 90 ثانية: خسارة حجز المنسحب/الغائب وإعادة حجز الآخر دون مكافأة. غياب الطرفين أو تأخر جدولة الخادم يؤدي إلى الإلغاء والاسترداد. القرار النهائي سري وثابت. تُحفظ دردشة المباراة للمراجعة الإدارية حتى 30 يومًا.
- الترويج: من قائمة منشورك العام في صفحتك الشخصية اختر «ترويج المنشور»، وحدد 1–30 يومًا وملاحظات اختيارية. راجع الطلب من شاشة «ترويج المنشورات» في الإدارة. المعتمد يظهر في الخلاصة بعلامة «منشور مروّج» ويظل خاضعًا للحظر والخصوصية وفلاتر الخلاصة. تغيير المنشور إلى خاص أو إخفاؤه يلغي الترويج؛ إعادته إلى عام لا تعيد الترويج تلقائيًا. ينتهي الظهور بانتهاء المدة.
- لم تُحدد أسعار أو آلية دفع للترويج؛ الموجود طلب واعتماد إداري، دون خصم مالي أو بوابة دفع.

## التحقق وحدوده

نجح تحليل Dart الكامل دون أخطاء. نجحت 52 اختبارات الإدارة و80 تحققًا فعليًا لدوال SQL على PostgreSQL مضمّن ببيانات اختبار معزولة. نجح اختبار واجهة الإدارة في Chromium بواجهات API تجريبية، بما فيها اعتماد الترويج. نجح التحقق من صياغة TypeScript. لم تُحذف ملفات مصدر من النسختين المرفوعتين.

لم تُنفّذ اختبارات Flutter الأصلية أو بناء APK/EXE أو تجربة جهازين أو نشر Supabase الحي. لم تُشغّل pg_cron محليًا. لذلك يلزم تشغيل أوامر Flutter أعلاه ثم اختبار جهازين بعد النشر. اختبارات SQL موجودة في verification وتُشغّل عبر npm install ثم npm test.

اختبر: تسجيل عضو مجتمع وطالب؛ الحالات الثلاث للقرار النهائي؛ الانقطاع والعودة والانسحاب؛ تعديل رصيد مرة واحدة؛ ترويج منشور عام واعتماده، ثم تغييره إلى خاص؛ ومنع منشور غير مملوك من طلب الترويج. تأكد من بقاء عدد الأسئلة المنشورة 2000 ونجاح مهمة الجدولة.
