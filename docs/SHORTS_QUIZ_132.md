# Zameel 132 — Shorts and Quiz validation candidate

This is a source update candidate, not a prebuilt APK or a claim of production readiness. No live database, service, billing or deployment was changed by preparing it.

## Implemented
Existing Clips become Zameel Shorts using the same clip records, likes, comments, reports, storage and clips feature flag. New uploads begin public and accept durations from 1 to 120 seconds. Existing content and its audiences remain; existing management privacy controls remain available. The home gateway opens a curved thumbnail fan with only Zameel Shorts, Surprise me, and Swipe and open your world. The viewer supports vertical navigation, playback pause, remembered mute, author profiles, likes/comments/share, save, hide, block, reporting and own deletion. Profile and saved Shorts grids paginate. Recommendations combine randomness with watch, like and save signals and exclude blocked accounts and hidden content. This is a first recommendation algorithm, not a trained interest model.

A view is recorded after three reported seconds and server session age checks, at most once per viewer per rolling 24 hours; author views do not count. These are application counters, not fraud-proof advertising measurements. Existing cache-only video playback and route/background pause controls are retained. The fan reuses the account-isolated home snapshot. Existing clips without cover images show a neutral tile; this package does not backfill covers.

Android/iOS uploads use the free video_compress package (3.1.4), keep a compressed result only if smaller than the original, and generate a thumbnail unless a custom cover is chosen. Re-encoding is not mathematically lossless and visual quality must be checked on real devices. Web requires a chosen cover and uploads the original video; there is no free server transcoder or adaptive bitrate pipeline here. A cover can be selected for desktop as well.

Quiz has bilingual four-choice questions, one point per correct answer, red wrong choice / green correct choice, automatic next question after feedback, no countdown, server-side resumable pending questions, question ordinals, top ten names/photos and medals, own ranking and question-error reports. Correct-answer totals determine levels: 0–15 introductory, 16–30 easy, 31–80 medium, 81–140 hard, 141–350 advanced, 351+ expert. Stage quotas are 16, 15, 50, 60 and 210 successful answers. Incorrect attempts do not advance a level. A mastered question cannot award another point. Unseen questions at the current level are preferred; previously wrong, unmastered questions are retried when fresh questions are exhausted. Exhausted reviewed content shows an honest availability message instead of advancing a level.

The Quiz shortcut replaces the Books shortcut in the home quick bar only. Books remain elsewhere. Quiz defaults hidden until explicitly enabled. Question/answer tables are private, authenticated RPCs disclose the answer only after an answer submission, and server review records a particular revision. Admin Quiz supports bilingual drafts, source URLs, review and publication, disabling, reports, paginated lists and batched JSON import. Existing advertisements, sales and reporting controls were not intentionally changed.

## Bank import format
JSON file containing an array of objects, each with level (1..6), question_ar, question_en, options_ar (4 strings), options_en (4 strings), correct_index (0..3), source_url (HTTPS). The index must refer to matching translated choices. Duplicate normalized question text is rejected. Batches contain at most 100 items and are atomic; if an import fails, correct the failing batch rather than retrying every already committed batch. All imported items start as drafts. Reviewer checks both languages, four distinct options, the unique correct answer, stable facts, difficulty and the source before approving the exact revision.

## Preservation and limits
Existing media snapshots, advertisements and moderation continue using their prior mechanisms. Already downloaded/offline copies and previously issued signed URLs are not instantly revoked when network access is unavailable; refreshing metadata after reconnect remains necessary. No package can guarantee zero network wait for unseen media. This update does not create a paid CDN, server compression, an independently human-approved question bank or a store-ready iOS build. Keep the previous verified release/tag and backups until acceptance passes.
