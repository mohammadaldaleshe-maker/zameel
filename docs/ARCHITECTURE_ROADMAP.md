# Zameel implementation roadmap

The supplied product specification defines Zameel as social-first and education-first, with the Feed as the heart of the application. The implementation should therefore stabilize the foundation before Meet, AI, payments and advertising.

### Wave 1 — MVP foundation
- Authentication and verification
- Academic hierarchy
- Profiles and privacy
- Search and friendships
- Feed and post interactions
- Faculty communities and groups
- Books
- Core admin capabilities

### Wave 2 — communication
- Direct messages
- Files and voice messages
- Notifications
- Block/report/mute

### Wave 3 — media and identity
- Stories / Status / Clips
- Anonymous messaging safeguards
- Referrals and reputation

### Wave 4 — commercial
- Companies
- Marketplace
- Jobs/internships
- Ads

### Wave 5 — advanced
- Meetings
- AI assistant/search
- Payments

Cross-cutting requirements: precise permissions, audit logs, rate limiting, secure storage, moderation, pagination, loading/empty/error states, retry behavior, localization, accessibility, analytics and automated tests.
