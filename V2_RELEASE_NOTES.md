# Zameel v2.0.0 — Foundation Package

This package is a staged V2 foundation built on the current Zameel 1.3.8 community-scoped codebase.

Included:
- Zameel v2 central product hub
- Existing modules wired into the V2 information architecture
- Version bumped to 2.0.0+1
- Master product/engineering specification
- Non-destructive V2 target schema plan
- Existing community scoping migration 019 retained
- Existing security hardening and production feed fixes retained

Important:
- This is NOT a claim that every V2 feature is already backed by production database logic.
- AI generation, opportunity matching, canonical academic IDs, advanced communities, reputation,
  and some campus features require their own backend implementation and tests.
- Apply migration 019 in Supabase before testing scoped community/study access.
- Do not execute migration 020 until it is reconciled with the live schema.
