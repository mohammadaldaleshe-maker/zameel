# Zameel AI 046

This update replaces the simulated AI responses with a real, server-side Gemini integration.

## Included

- Real assistant, summarization, and explanation modes.
- Gemini key remains inside Supabase Edge Function secrets and is never shipped in Flutter.
- 50 model requests per user per day, enforced atomically on the server.
- Approved FAQ answers do not consume the Gemini quota.
- Optional conversation memory and a user-controlled clear-history action.
- Owner/admin screen for adding, editing, and deleting approved answers.
- Verified university knowledge-source tables with RLS.
- Basic redaction of phone numbers, email addresses, and 10-digit personal identifiers.
- Honest failure and privacy notices in the UI.

## Deploy

1. Run `supabase/migrations/046_zameel_ai.sql` once in Supabase SQL Editor.
2. Confirm that the `GEMINI_API_KEY` secret exists.
3. Deploy the function from the repository root:

```powershell
npx supabase@latest functions deploy zameel-ai --project-ref jwuqyykjmltroneqtjoc
```

4. Validate Flutter before pushing:

```powershell
dart format lib/screens/ai/ai_screen.dart lib/screens/ai/ai_faq_admin_screen.dart lib/services/zameel_ai_service.dart
flutter analyze
flutter test
```

The default provider model is `gemini-3.5-flash-lite`. It can be overridden later with the optional Supabase secret `GEMINI_MODEL`.
